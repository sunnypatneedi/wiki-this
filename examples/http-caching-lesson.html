Freshness lifetime

From the HTTP Caching wiki. A local preview.

1. Concept

A cache may reuse a response only while that response is fresh. The usual way to set that lifetime is Cache-Control: max-age, a number of seconds counted from the origin response.

2. Example

A stylesheet is served with Cache-Control: max-age=86400. For the next day, the browser can use its stored copy without asking the server again. After that, it is no longer fresh.

4. Check

When freshness ends, a cache can send If-None-Match with the stored ETag. A 304 Not Modified lets it keep the body it already has.

5. Recap

Freshness is a lifetime. Validation is what happens after. Shared caches have stricter rules than a browser cache.
