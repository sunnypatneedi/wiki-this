1. Concept

A stored response is fresh while its current age is less than its freshness lifetime. Cache-Control: max-age sets that lifetime in seconds. Existing age matters too.

2. Example

A browser cache stores a reusable stylesheet with Cache-Control: max-age=86400. With a current age of 3600 seconds, it has 82800 seconds of freshness left. Once its age reaches 86400 seconds, the response is stale.

3. Try it

A shared cache receives a response with Cache-Control: private, max-age=600. What should it do?

Choose one

Read the explanation

An unqualified private directive prevents storage in a shared cache. A freshness lifetime does not override that restriction.

4. Check

A reusable response has max-age=600 and a current age of 480 seconds. How much freshness remains?

Check your answer

120 seconds. Subtract current age from the freshness lifetime. When the current age reaches 600 seconds, the response is stale.

5. Recap

Freshness compares lifetime with current age. Storage rules still apply. A stale response may be validated with a conditional request when an appropriate validator is available; freshness and validation answer different questions.
