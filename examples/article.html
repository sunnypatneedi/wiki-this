Freshness lifetime

How long a stored response can be reused before it must be checked again.

Source
MDN HTTP caching guide · RFC 9111 §4.2 · 6 terms

A cache may reuse a response while it is still fresh. Freshness is usually set with Cache-Control and max-age.

When that lifetime ends, the cache must not serve the copy as fresh. It can send the stored ETag with If-None-Match and accept 304 Not Modified, or it can request a new representation.

Shared caches follow extra rules. private keeps a response in a single-user cache. s-maxage sets a lifetime that applies only to shared caches.
